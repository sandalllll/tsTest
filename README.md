Практикум по TypeScript
Node.js v24.16.0
Для установки: npm ci
Для проверки типов: npm run check
Для компиляции: npm run build
Для запуска: node dist/task<N>.js, где N - номер задачи

task1.js - задание о перегрузках функций. В выводе - информация о вызванных перегруженных функциях.
task2.js - задание о кортежах и перечислениях. В выводе - информация о вызванных функциях описания цвета. Выбрасываются RangeError исключения для неверных значений цвета.
task3.js - задание о функциях сторожах и псевдонимах типов. В выводе - информация о вызванных функциях проверки UUID и выдаче информации о пользователе.
task4.js - задание о иммутабельных операциях. В выводе - информация о вызванных функциях добавления и удаления тегов, объединения групп тегов.
task5.js - задание о пайплайнах и обобщённых типах. В выводе - информация о вызванной перегруженной "конвейерной" функции.
task6.js - задание о иммутабельных операциях и reduce. В выводе - информация о вызванной функции подсчета сумм для разных групп.
task7.js - задание о иммутабельных операциях и разбиении массива. В выводе - информация о многократно вызванной с разными аргументами функции разбиения массива. Выбрасываются RangeError исключения для неверных значений размера разбиения.
task8.js - задание о интерфейсах и классах для хранилища. В выводе - информация о созданных объектах и вызванных функциях интерфейса, этим самым объектом реализуемым. Выбрасываются Error исключения для повторяющихся значений id.
task9.js - задание о глубокой заморозке и DeepReadonly. В выводе - информаци о вызванных функциях проверки возможности изменить некоторые части глубоко замороженного объекта.
